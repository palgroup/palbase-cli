# T007 — `notifications remove` ad→kimlik · DONE · **P0-4 KAPANDI**

## Kusur
CLI sağlayıcı ADINI yol parçası olarak gönderiyordu; modül `WHERE id = $1` ile siliyor ve
hiçbir yapılandırmanın kimliği "apns" değil → **her `remove` 404 alıyordu**, help ise
"It stops delivering" diyordu.

## Neden hayatta kaldı
Paketin kendi testi **kusuru doğruluyordu**: `assert.Equal("/v1/management/notifications/providers/apns")`.
Test hatayla hemfikirdi, o yüzden kimse görmedi. Test gerçek sözleşmeye çevrildi (zayıflatma değil —
yanlış assertion'ın düzeltilmesi) ve kırmızı orada çıktı.

## Çözüm (C-2)
`providerConfigID` → `GET providers`, ada göre (büyük/küçük harf duyarsız) eşle, kimliği döndür.
- 0 eşleşme → adlandırılmış hata + `palbase notifications providers` yönlendirmesi
- 2+ eşleşme → **reddediyor**; birini seçmek, kişinin adlandırmadığı bir göndericiyi silmek olurdu
